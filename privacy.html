Privacy Policy

🔒 Privacy-First — I tuoi file, il tuo dispositivo

In breve: OraKit non raccoglie, trasmette o condivide alcun dato personale con terze parti. Tutti i tuoi file restano sul tuo dispositivo. Se attivi iCloud, l'Archivio viene sincronizzato esclusivamente tramite la tua infrastruttura Apple. Il Vault resta sempre solo in locale.

1. Chi siamo

OraKit è un'applicazione iOS sviluppata da Giovanni Orabona (OraKit). Non operiamo server propri e non includiamo SDK di terze parti per analytics, pubblicità o tracciamento.

2. Dati che raccogliamo

Nessuno.

OraKit non raccoglie alcun dato personale. Non raccogliamo:

  • Dati identificativi personali
  • Dati di utilizzo o analytics
  • Informazioni sul dispositivo
  • Dati di localizzazione
  • Cookie o identificatori di tracciamento

3. Archiviazione dei file

I file che importi, scannerizzi o crei con OraKit sono conservati nella sandbox protetta dell'app sul tuo dispositivo.

Archivio (Archive): se attivi la sincronizzazione iCloud nelle impostazioni di sistema, i file dell'Archivio vengono sincronizzati tramite il tuo account iCloud personale (CloudKit / NSUbiquitousKeyValueStore). Questa comunicazione avviene esclusivamente tra il tuo dispositivo e i server Apple, sotto il tuo account. Noi non abbiamo accesso ai tuoi dati iCloud.

Vault Sicuro: i file nel Vault sono cifrati localmente con AES-256-GCM. La chiave è derivata dalla tua password tramite HKDF-SHA256. Non memorizziamo la tua password — solo un hash marker nel Keychain del dispositivo. Il Vault non viene mai sincronizzato con iCloud e resta sempre solo in locale.

4. Connessioni di rete

OraKit non contatta server propri. Le uniche connessioni di rete possibili sono:

  • iCloud (opzionale): se attivato dall'utente nelle impostazioni di sistema, per sincronizzare l'Archivio tramite Apple CloudKit.
  • Web → PDF (opzionale): quando l'utente usa lo strumento Web → PDF, l'app carica la pagina web indicata tramite WebKit per generare un PDF. Nessun dato viene inviato a nostri server.

Tutte le altre funzionalità operano completamente offline, senza alcuna connessione di rete.

5. Accesso alla fotocamera

OraKit richiede l'accesso alla fotocamera esclusivamente per la funzionalità Scanner + OCR. Le immagini acquisite restano in locale e non vengono mai trasmesse.

6. Biometria

Se attivi il blocco biometrico (Face ID / Touch ID), l'autenticazione è gestita interamente dal framework LocalAuthentication di iOS. Nessun dato biometrico è accessibile all'app.

7. Condivisione dati con terzi

Non condividiamo alcun dato con terze parti. Non utilizziamo SDK di analytics, pubblicità o crash reporting.

8. Sicurezza

Utilizziamo le tecnologie di sicurezza native di iOS:

  • Sandbox app di iOS per l'isolamento dei file
  • Keychain per i dati crittografici sensibili
  • CryptoKit (AES-256-GCM) per la cifratura dei file nel Vault
  • CloudKit di Apple per la sincronizzazione iCloud (solo Archivio, se attivato)

9. Diritti dell'utente

Poiché non raccogliamo dati personali, non esiste alcun dato da richiedere, correggere o eliminare presso di noi. Puoi disinstallare l'app in qualsiasi momento — tutti i dati locali verranno rimossi automaticamente da iOS. Per i dati iCloud, puoi gestirli tramite le impostazioni del tuo account Apple.

10. Modifiche alla policy

Eventuali modifiche a questa policy saranno pubblicate su questa pagina con la data di aggiornamento. Ti invitiamo a controllare periodicamente.

11. Contatti

Per domande sulla privacy: giovanni.orabona@yahoo.com

Privacy Policy

Last updated: March 11, 2026

🔒 Privacy-First — Your files, your device

In short: OraKit does not collect, transmit, or share any personal data with third parties. All your files stay on your device. If you enable iCloud, the Archive is synced exclusively through your Apple infrastructure. The Vault always stays local only.

1. Who we are

OraKit is an iOS application developed by Giovanni Orabona (OraKit). We do not operate our own servers and do not include third-party SDKs for analytics, advertising, or tracking.

2. Data we collect

None.

OraKit does not collect any personal data. We do not collect:

  • Personal identification data
  • Usage data or analytics
  • Device information
  • Location data
  • Cookies or tracking identifiers

3. File storage

Files you import, scan, or create with OraKit are stored in the app's protected sandbox on your device.

Archive: if you enable iCloud sync in your system settings, Archive files are synced through your personal iCloud account (CloudKit / NSUbiquitousKeyValueStore). This communication happens exclusively between your device and Apple's servers, under your account. We have no access to your iCloud data.

Secure Vault: files in the Vault are encrypted locally with AES-256-GCM. The key is derived from your password using HKDF-SHA256. We do not store your password — only a marker hash in the device Keychain. The Vault is never synced to iCloud and always stays local only.

4. Network connections

OraKit does not contact our own servers. The only possible network connections are:

  • iCloud (optional): if enabled by the user in system settings, to sync the Archive through Apple CloudKit.
  • Web → PDF (optional): when the user uses the Web → PDF tool, the app loads the specified web page through WebKit to generate a PDF. No data is sent to our servers.

All other features operate completely offline, with no network connections.

5. Camera access

OraKit requests camera access exclusively for the Scanner + OCR feature. Scanned images remain local and are never transmitted.

6. Biometrics

If you enable biometric lock (Face ID / Touch ID), authentication is handled entirely by iOS's LocalAuthentication framework. No biometric data is accessible to the app.

7. Third-party data sharing

We do not share any data with third parties. We do not use analytics, advertising, or crash reporting SDKs.

8. Security

We use iOS native security technologies:

  • iOS app sandbox for file isolation
  • Keychain for sensitive cryptographic data
  • CryptoKit (AES-256-GCM) for Vault file encryption
  • Apple CloudKit for iCloud sync (Archive only, if enabled)

9. User rights

Since we do not collect personal data, there is no data to request, correct, or delete from us. You can uninstall the app at any time — all local data will be automatically removed by iOS. For iCloud data, you can manage it through your Apple account settings.

10. Changes to this policy

Any changes to this policy will be published on this page with the update date. We encourage you to check periodically.

11. Contact

For privacy questions: giovanni.orabona@yahoo.com
